# Gift Planner — система планирования подарков

## Назначение
Консольное приложение для планирования подарков: хранение информации о людях, событиях и идеях подарков, а также подготовка к будущим датам.

## Целевая аудитория
Пользователи, которые хотят заранее планировать подарки для друзей, родственников и коллег, чтобы ничего не забыть и подготовиться вовремя.

## Предметная область
Управление людьми, событиями (дни рождения, праздники, важные даты) и подарками, которые пользователь планирует вручить.

## Основные классы

### Person — человек
Атрибуты: `id`, `name`
Методы: `__str__()`

### Event — событие
Атрибуты: `id`, `person` (объект `Person`), `date`
Методы: `days_until()`, `__str__()`

### Gift — подарок
Атрибуты: `id`, `person` (объект `Person`), `idea`, `is_done`
Методы: `mark_done()`, `__str__()`

## Взаимодействие объектов
- `Event.person` — ссылка на объект `Person`
- `Gift.person` — ссылка на объект `Person`
- В JSON хранятся идентификаторы (`person_id`), при загрузке восстанавливаются связи с объектами.

## Структура проекта
- `main.py` — точка входа, меню;
- `storage.py` — загрузка и сохранение JSON;
- `utils.py` — вспомогательные функции;
- `models/` — пакет с классами:
  - `persons.py` — класс `Person` и функции;
  - `events.py` — класс `Event` и функции;
  - `gifts.py` — класс `Gift` и функции;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты pytest.
