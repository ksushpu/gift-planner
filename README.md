# Gift Planner — система планирования подарков

## Назначение
Веб-приложение на Django для планирования подарков: хранения информации
о людях, событиях и идеях подарков.

## Целевая аудитория
Пользователи, которые хотят заранее планировать подарки для друзей,
родственников и коллег.

## Предметная область
Управление людьми, событиями и подарками. **Подарок** — главная
сущность: он связывает **человека** (кому дарят) и **событие** (по какому
поводу).

## Технологии
- Python 3
- Django 5.2
- Django ORM
- Django Template Language (DTL)
- HTML, CSS, JavaScript, Bootstrap 5.3
- SQLite
- pytest, flake8

## Модели данных (Django ORM)
- **Person** (`people.models`) — человек; поля: `name`
- **Event** (`events.models`) — событие; поля: `person` (ForeignKey), `title`, `date`;
  метод `days_until()`
- **Gift** (`gifts.models`) — подарок; поля: `person` (ForeignKey), `event` (ForeignKey),
  `idea`, `is_done`; метод `mark_done()`

Связи:
- одно событие относится к одному человеку (`Event.person`);
- один подарок относится к одному человеку и одному событию;
- обратные связи: `person.events`, `person.gifts`, `event.gifts`.

## Страницы веб-интерфейса
| URL | Что показывает |
|---|---|
| `/` | главная страница |
| `/people/` | список людей (поиск по имени) |
| `/events/` | список событий (поиск, фильтр предстоящих) |
| `/events/<id>/` | страница события |
| `/gifts/` | список подарков (поиск, фильтры, сортировка, пагинация) |
| `/gifts/<id>/` | страница подарка |
| `/gifts/statistics/` | статистика подарков |

## Структура проекта
- `manage.py` — управление Django-проектом;
- `giftplanner/` — настройки Django-проекта;
- `templates/` — базовый шаблон `base.html` и навигация;
- `homepage/` — главная страница и статические файлы;
- `people/` — модель Person, страницы людей;
- `events/` — модель Event, страницы событий;
- `gifts/` — модель Gift, страницы подарков и статистики;
- `models/` — классы предметной области (ПР3, консольная версия);
- `db/` — скрипты работы с БД и переноса данных в ORM;
- `sql/` — SQL-скрипты предыдущих практических работ;
- `storage.py` — загрузка и сохранение JSON;
- `main.py` — консольная версия;
- `data/` — JSON-файлы и исходная база `gift_planner.sqlite` (ПР7);
- `db.sqlite3` — целевая база Django (создаётся локально, в Git не входит);
- `tests/` — тесты pytest.

## База данных
После ПР9 приложение работает с базой Django `db.sqlite3` через ORM.
Исходная база ПР7 `data/gift_planner.sqlite` сохранена как источник данных
для переноса и не изменяется миграциями Django.

**Порядок подготовки базы:**
1. `python manage.py migrate` — создать таблицы по моделям;
2. `python db/inspect_source_db.py` — проверить исходную базу;
3. `python db/import_sqlite_to_orm.py` — перенести данные в `db.sqlite3`.

## Запуск проекта
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python db/import_sqlite_to_orm.py
python manage.py runserver
```

Откройте в браузере: http://127.0.0.1:8000/
