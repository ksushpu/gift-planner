# Gift Planner — система планирования подарков

## Назначение
Консольное приложение с веб-интерфейсом на Django для планирования
подарков: хранения информации о людях, событиях и идеях подарков.

## Целевая аудитория
Пользователи, которые хотят заранее планировать подарки для друзей,
родственников и коллег.

## Предметная область
Управление людьми, событиями и подарками. **Подарок** — главная
сущность: он связывает **человека** (кому дарят) и **событие** (по какому
поводу).

## Основные сущности

### Person — человек
Атрибуты: `id`, `name`
Методы: `__str__()`

### Event — событие
Атрибуты: `id`, `person`, `title`, `date`
Методы: `days_until()`, `__str__()`

### Gift — подарок (главная сущность)
Атрибуты: `id`, `person`, `event`, `idea`, `is_done`
Методы: `mark_done()`, `__str__()`

## Взаимодействие объектов
- `Gift.person` — ссылка на объект `Person`;
- `Gift.event` — ссылка на объект `Event`;
- `Event.person` — ссылка на объект `Person`.

## Django Templates (Шаблоны)
HTML-страницы формируются с помощью Django Template Language. Генерация HTML в Python-коде (`views.py`) больше не используется — теперь view-функции передают данные через контекст (`context`) и вызывают функцию `render()`.
- **Базовый шаблон:** `templates/base.html` содержит общую структуру и блоки `{% block title %}` и `{% block content %}`.
- **Наследование:** дочерние страницы используют `{% extends "base.html" %}`.
- **Include:** повторяющиеся элементы (навигация, карточки подарков) вынесены в отдельные файлы и подключаются через `{% include %}`.
- **Циклы и условия:** используются `{% for %}`, `{% empty %}`, `{% if %}`.
- **Именованные URL:** ссылки формируются через `{% url %}` с использованием пространств имён (например, `{% url 'gifts:detail' gift.id %}`).
- **Фильтры:** используются фильтры `|length` и `|default`.

## Статические файлы
CSS, JavaScript и изображения подключены через механизм `static`.
- Файлы находятся в `homepage/static/homepage/`.
- В шаблоне используется тег `{% load static %}`.
- CSS: `{% static 'homepage/css/style.css' %}`
- JS: `{% static 'homepage/js/main.js' %}`
- Логотип: `{% static 'homepage/img/logo.png' %}`

## База данных SQLite
На этапе ПР7 в проект добавлен слой реляционного хранения данных на основе SQLite.

**Файл базы данных:** `data/gift_planner.sqlite`.

**Структура таблиц (файл `sql/schema.sql`):**
- `people` — люди (`id`, `name`);
- `events` — события (`id`, `person_id`, `title`, `date`);
- `gifts` — подарки (`id`, `person_id`, `event_id`, `idea`, `is_done`).

**Работа с базой:**
- `db/database.py` — подключение к SQLite (`PRAGMA foreign_keys = ON`);
- `db/import_json.py` — скрипт переноса данных из JSON в SQLite;
- `sql/queries.sql` — 10 SQL-запросов (SELECT, WHERE, JOIN, COUNT, GROUP BY, HAVING).

**Интеграция с Django:** представления в приложениях выполняют SQL-запросы через `sqlite3` и передают данные в шаблоны. Используются параметризованные запросы для защиты от инъекций. Добавлена страница статистики `/gifts/statistics/`.
