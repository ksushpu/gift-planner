# Gift Planner — система планирования подарков

## Назначение
Консольное приложение для планирования подарков: хранение информации о людях, событиях и идеях подарков, а также подготовка к будущим датам.

## Целевая аудитория
Пользователи, которые хотят заранее планировать подарки для друзей, родственников и коллег, чтобы ничего не забыть и подготовиться вовремя.

## Предметная область
Управление людьми, событиями (дни рождения, праздники, важные даты) и подарками, которые пользователь планирует вручить.

## Основные сущности
- Пользователь
- Человек (кому дарят подарок)
- Событие (день рождения, праздник, дата)
- Подарок (идея подарка, статус подготовки)

## Основные функции
- Добавление человека (`add_person`)
- Добавление события (`add_event`)
- Добавление идеи подарка (`add_gift_idea`)
- Просмотр списка событий с сортировкой по дате (`sort_events_by_date`)
- Поиск событий по человеку (`find_events_by_person`)
- Простой сценарий планирования подарка (`plan_gift`)

## Структура проекта
- `main.py` — точка входа, меню и взаимодействие с пользователем;
- `logic.py` — функции обработки данных (люди, события, подарки);
- `storage.py` — загрузка и сохранение данных в JSON-файлах;
- `utils.py` — вспомогательные функции безопасного ввода;
- `data/` — JSON-файлы с данными (`people.json`, `events.json`, `gifts.json`);
- `tests/` — автоматизированные тесты pytest;
- `README.md` — документация проекта;
- `requirements.txt` — зависимости проекта.
