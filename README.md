# Gift Planner — система планирования подарков

## Назначение
Консольное приложение с веб-интерфейсом на Django для планирования
подарков: хранения информации о людях, событиях и идеях подарков.

## Целевая аудитория
Пользователи, которые хотят заранее планировать подарки для друзей,
родственников и коллег.

## Предметная область
Управление людьми, событиями и подарками. **Подарок** — главная
сущность: он связывает **человека** (кому дарят) и **событие** (по какому
поводу).

## Основные сущности

### Person — человек
Атрибуты: `id`, `name`
Методы: `__str__()`

### Event — событие
Атрибуты: `id`, `person`, `title`, `date`
Методы: `days_until()`, `__str__()`

### Gift — подарок (главная сущность)
Атрибуты: `id`, `person`, `event`, `idea`, `is_done`
Методы: `mark_done()`, `__str__()`

## Взаимодействие объектов
- `Gift.person` — ссылка на объект `Person`;
- `Gift.event` — ссылка на объект `Event`;
- `Event.person` — ссылка на объект `Person`.

## Используемые технологии
- Python 3
- Django 5.2
- HTML, CSS, Bootstrap 5.3
- pytest, flake8

## Структура проекта
- `manage.py` — управление Django-проектом;
- `giftplanner/` — настройки Django-проекта;
- `homepage/` — главная страница и общий каркас `page()`;
- `people/` — страницы людей;
- `events/` — страницы событий;
- `gifts/` — страницы подарков;
- `models/` — классы предметной области (ПР3);
- `storage.py` — загрузка и сохранение JSON;
- `main.py` — консольная версия (сохранена);
- `data/` — JSON-файлы;
- `tests/` — тесты pytest.

## Страницы веб-интерфейса
| URL | Что показывает |
|---|---|
| `/` | главная страница |
| `/people/` | список людей |
| `/events/` | список событий |
| `/events/<id>/` | страница события |
| `/gifts/` | список подарков |
| `/gifts/<id>/` | страница подарка |
